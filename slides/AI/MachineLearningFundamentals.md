# 機械学習の基本（Machine Learning Fundamentals）

## 1. 学習データ（Training Data）
モデル作成の第一歩であり、質（`Garbage in, Garbage out`）が結果を左右する最も重要なフェーズです。

* **教師あり・教師なしの分類**
  * **正解ラベルあり（Labeled data）:** 入力データと正解データがセットになったもの。
  * **正解ラベルなし（Unlabeled data）:** 正解ラベルが付与されていないデータ。
* **データの構造**
  * **構造化データ（Structured data）:** データベースや表形式に整理されたデータ。
  * **非構造化データ（Unstructured data）:** 画像・音声・テキストなど、規則的な構造を持たないデータ。

---

## 2. 機械学習アルゴリズム（Machine Learning Process）
トレーニングデータを読み込ませて学習させる手法には、主に3つのカテゴリがあります。

| 学習タイプ | 説明 |
| :--- | :--- |
| **教師あり学習（Supervised Learning）** | 正解ラベル付きデータで学習し、未知の入力に対して結果を予測するマッピング関数を作成する。 |
| **教師なし学習（Unsupervised Learning）** | 正解ラベルのないデータから、データ内に潜むパターンや構造・関係性を発見する。 |
| **強化学習（Reinforcement Learning）** | 報酬やペナルティのフィードバックを受けながら、試行錯誤を通じて最適な意思決定を学ぶ。 |

---

## 3. インファレンス（Inferencing / 推論）
学習済みのモデルを使って、新しいデータから予測や判断を行うプロセスです。

### リアルタイム推論（Real-time Inferencing）
* **特徴:** 新しいデータが入ってきた際、即座に処理を行って結果を返す方式。
* **用途:** チャットボットの応答生成、自動運転車の障害物検知など即時性が求められる処理。

### バッチ推論（Batch Inferencing）
* **特徴:** 大量のデータを一定時間ごとにまとめて一括で処理する方式。
* **用途:** 定期的なデータ分析や売り上げ予測など、処理スピードよりも正確性や一括処理が重視される場面。
